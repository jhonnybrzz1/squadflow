# Phase 0 — Discovery Brief Template

> Template inspirado na skill BMAD `business-analyst`.
> Usado pelo serviço `phase0-discovery.ts` quando a demanda chega vaga (ou quando
> o classificador indica baixa confiança) ANTES do Refinador.
>
> Frameworks aplicados:
>
> - **5 Whys** — para chegar à raiz do problema
> - **Jobs-to-be-Done** — o que o usuário está tentando alcançar
> - **SMART Goals** — objetivos Specific, Measurable, Achievable, Relevant, Time-bound
